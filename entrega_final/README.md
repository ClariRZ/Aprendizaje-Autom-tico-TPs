# Entrega final

[`TP1.md`](TP1.md) es la versión editable en Git de
[`TP1_desercion.pdf`](TP1_desercion.pdf), que se conserva como copia de la
versión cerrada. El texto contiene cinco tablas en Markdown y referencias a
las ocho figuras de `figuras/` (la Figura 2 tiene dos paneles).

Para corregir la entrega, editá `TP1.md` y los SVG correspondientes. El PDF
original no se actualiza automáticamente cuando cambia el Markdown.

Antes de entregar, completá `Integrantes: [completar]` con los nombres del
grupo y volvé a revisar que tablas, cifras y figuras coincidan con el PDF
si modificaste el texto.

El [recorrido en diez pasos](../README.md#resolución-paso-a-paso) reúne los
scripts y las decisiones que fundamentan el informe. Los experimentos
adicionales y la comparación temporal están identificados en `AA privada/`.
