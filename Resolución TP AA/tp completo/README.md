# Primera resolución integrada

[`TP1_completo.md`](TP1_completo.md) conserva el informe de la primera
resolución, sus gráficos y el vínculo con el código del TP. Es material de
desarrollo y estudio: la [entrega final editable](../../entrega_final/TP1.md)
reproduce el PDF y es el texto principal para entregar.

## Cómo seguir sus resultados

- [`GUIA_PASO_A_PASO.md`](GUIA_PASO_A_PASO.md) explica el recorrido desde la
  partición y el EDA de train hasta la evaluación.
- [`trazabilidad.md`](trazabilidad.md) indica el origen de las cifras y de las
  verificaciones adicionales.
- `graficos/` contiene las figuras citadas por el informe integrado.
- `generar_figuras_eda_sintesis.py` regenera los dos gráficos descriptivos del
  EDA; requiere antes reconstruir el CSV de `00_base_de_datos/`.

El experimento adicional sobre información disponible por etapas está en
[`AA privada/02_alternativa_temporal`](../../AA%20privada/02_alternativa_temporal/README.md).
